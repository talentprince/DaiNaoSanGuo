# 武将库与品级规则 · Demo 0.8

2026-10-31。当前实现，验收状态见根目录SPEC.md。共40位：普通5、骁将8、名将17、神将10。

普通/骁将/名将/神将的攻击型主动技能分别最多1/2/3/全体目标；普通无治疗，骁将单体治疗，名将全体治疗，神将全体治疗并附状态。华佗20%群疗+12%生命护盾，司马懿16%群疗+20%攻击，状态均6秒、刷新不无限叠加。其他细节以SPEC.md为准。

原玩家保留已拥有武将与装备；关羽、赵云、诸葛亮升为神将，刘备等重新分档后，旧三将阵容按新上限修复，多余高品级槽位换小兵，所有权保留。主线只送非神将。

风格参考方向为《英雄没有闪》这类暗黑Q版、重装备、横向卷轴体验，使用原创程序化可动图形，不使用参考游戏素材。[官方参考](https://www.37.com/yxmys/index.html)。模型放大并允许适度遮挡，武器按人物特征绘制。
