## 内测资源规则

当前RuntimeConfig.serviceMode=local、localProfile=experience。真实手机/远程初次使用独立experience档，从旧常规档单向复制进度，随后赠脑铢1000万、呆币100万、脑勋100万、将魂10万、升级经验1亿。首次到账弹层暂停战斗；顶部“内测”标记，手机点击可看说明。

grantVersion=1与进度同信封保存；升级/抽卡消费后重载不补满。原常规档、满级开发档保持独立；存储不可写则会话仍可体验并标记未保存。补给不是正式奖励，也不用于评价两周经济。公开版本须切回standard，未来云端不导入体验资源。
