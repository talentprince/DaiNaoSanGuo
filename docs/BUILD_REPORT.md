# 验收与构建记录

## 0.19.0 r19a · 五十章与整装成长

2026-11-06（上海时间）。类型检查与 230 项测试通过。Cocos 浏览器触控通过五档筛选、粉装类型限制、续火溢出确认、第 50 章跳转和魔王八档奖品查看。

Creator 3.8.8 构建微信竖屏包并核对源码指纹。上传前预检主包 3,985,181 字节、音频分包 1,338,202 字节。微信开发者工具确认 0.19.0 开发版本上传成功，统计主包 3,965,775 字节、音频分包 1,338,149 字节。体验版标记及手机复测待后台确认。

## 0.18.2 r18n · 内测反馈修复

2026-11-06（上海时间）。本地类型检查与 224 项测试通过。浏览器触控复测装备卸下、转交入口和一键分解，验证赤门清场后出现三个传送圈、封坛闪光、敌人跳出与落地，以及战斗镜头在终结技后复位。

Creator 3.8.8 完成微信小游戏竖屏构建，源码指纹与项目一致。预检主包 3,962,076 字节、音频分包 1,338,202 字节。微信开发者工具确认 0.18.2 开发版本上传成功，统计主包 3,942,661 字节、音频分包 1,338,149 字节。用户已确认可以体验。
