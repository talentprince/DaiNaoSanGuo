# 首版设计范围

游戏名称：呆脑三国。宣传语：呆萌武将，大闹三国！

目标：先实现电脑可预览的战斗 Demo，再验证微信小游戏构建。

- 画面：2D、竖屏，设计分辨率 720 × 1280，横向交战。
- 我方：关羽、张飞、赵云、诸葛亮、刘备，先使用带名字的颜色占位图。
- 敌方：黄巾军，数量、生命、攻击、防御、攻击间隔通过配置定义。
- 流程：进入场景 → 自动攻击 → 受伤/死亡 → 胜负结算 → 重新开始。
- 后续小任务：一个主动技能、简单本地奖励。
- 暂缓：正式美术、装备词条、羁绊、离线收益、后端、登录、广告和支付。

参考《英雄没有闪》的自动战斗与成长体验，角色、美术、UI 和实现保持原创。
