# 当前游戏设计范围

《呆脑三国》：呆萌武将，大闹三国！2D竖屏，程序化可动角色，目标平台为微信小游戏。

- 主线：持续向右行军，清怪积秘境进度召Boss，击败继续推关，失败重打。
- 武将：小将、骁将、名将、神将四档；剧情、呆币招募和副本军功任选。
- 经济：主线首通少量呆币，24h挂机最多一发十连；副本提供额外呆币和军功。
- 副本：城门别闹、全服讨董、三将闹五关、草船借宝。
- 战斗：主线横向行军；Boss上下对峙；攻城两将上城和可破坏城墙；三将3v5向中间接敌。
- 补位：刀盾、长枪、弓箭三兵种，武将不足自动补齐。
- 养成：全队升级、武器掉落、背包穿戴与本地保存。

具体规则和已完成/未完成状态以根目录SPEC.md为准。数值见EXPANSION_0.5.md，表现见BATTLE_STYLE_0.6.md。当前真实玩家攻守、全服排名和服务端账本尚未接入，未发布。
