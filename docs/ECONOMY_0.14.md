# 0.14 经济与成长参数

2026-10-31。当前规则；旧0.5/0.8数值已被本文件覆盖。所有时钟/奖励当前在本地运行，非线上防作弊账本。

## 唯一参数源

GrowthConfig：MAX_STAGE999、MAX_LEVEL300、XP_DAILY_MS=4h、MEDAL_DAILY_CAP100、SIGNATURE_COST700、MAX_STARS6。
ProgressStore：资源事务、日计数、兑换、升星、领取、结算去重。

| 项 | 公式/数值 |
| --- | --- |
| 等级倍率 | 1.055^(level−1) |
| 主线难度倍率 | 1.09^min(9,stage−1) × 1.014^max(0,stage−10) × 1.05^floor(stage/50) |
| 升级经验 | floor(100+30×level^1.5) |
| 升级脑铢 | 80+level×40 |
| 挂机经验/分钟 | 12+最高已通关×0.35；未通首关为0 |
| 经验限制 | 缓存至多4h，领取日预算240分钟；上海日刷新；分领保留余数，倒时钟不重复领取 |
| 属性合成 | round((武将基础属性+三槽属性之和) × 等级倍率 × (1+0.16×(星级−1))) |
| 三将难度 | 使用主线难度倍率(stage×3)，保留5种战术特性 |
| 讨董/借宝地图档 | min(20,1+floor(最高已通关/50))；以主线倍率((档−1)×50+1)缩放；讨董同日首次档锁定 |

## 升星与专武

每位武将从1星到6星，成本20、40、60、100、160碎片（总380），先扣本将碎片再扣通用脑力。重复招募每次给20本将碎片，另外保留旧重复脑铢；升星不改变品级。3星起蓄能×1.1，6星攻击技能×1.2。

44把本人专武固定三项基础属性，随等级/星级参与最终属性合成。猛攻/破阵主动技能×1.25；速攻普攻间隔×0.85；护阵盾量×1.5；治疗量×1.25。专武不突破品级攻击人数限制，不可转给别人、不可重复兑换/分解。名将/神将独立机制深化待Review。

## 验证与调参流程

1. 修改唯一参数源，运行npm test和npm run typecheck。
2. npm run balance生成等级/阵容越关边界、30天经验投影。结果保存在BALANCE_0.14.md。
3. 试玩新手首关、首个瓶颈、换将/装备/升星后突破，以及每天4h经验的可解释性。
4. 用真实7/14天数据评估爽感、日常时长、资源净增与回访；未采集外部遥测，当前模拟不能替代长期验证。

当前报告假定脑铢足够，不模拟所有掉装与抽卡；999关按配置开放，未逐关人工打通。

## 0.14能量

普攻命中1；非城墙击杀全队存活武将18，击杀者另7。基础0.8/秒、断粮0.35/秒、世界Boss3/秒，星级与羁绊作用于增量，最多100。受伤不回能，初始0。主线/三将通关余能分别按武将与下一关保存，失败/手动重战清空，其他副本每次重新蓄能。开发档首次/主动测试充满，不在每次过关后补满。

当前独立满血模拟已按新能量重算：Lv1普通1星8关、神将1星70关、神将3星专武109关；该模拟不连续继承上一关余能，真实连续推图可能更高。报告不是长期留存或全部阵容最优解。

世界Boss现在每周三魔王轮换与弱点增伤，计分30秒后终结演出不增加成绩；日最高差额奖励与脑勋上限不变。详见WORLD_BOSSES_0.11.md。
