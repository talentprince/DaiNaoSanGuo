## 已回归保留的规则

- 普通/骁将/名将/神将攻击技能目标上限1/2/3/全场；普通无治疗，骁将单体，名将全体，神将全体加状态。
- 三将3v5最多1神将2名将；小兵刀/枪/弓可混编，无主动技能；守城2城上+3城下从6位置选。
- 主线999关、等级300、每天最多4h挂机经验；脑勋日100、脑力日20；名将/神将/专武兑换价格不变。
- 击杀为主回能、技能满才闪；主线/三将通关余能分别保存，失败/重战清空，其他副本从0蓄能。
- 普装不改持有兵器，只有本人专武改变外观且刃部发光；兑换、穿戴、升星和奖励去重仍由Store处理。
- 三周Boss轮换、弱点真实增伤、30秒锁分后2.8秒终结全灭再结算；局内配置快照固定。
- 常规、内测补给、本机满级档分别隔离；脑力改名不清存档；云端未接入时拒绝回落本地发可信奖励。
