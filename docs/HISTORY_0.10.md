## 2. 成长闭环

推图首通 → 剧情送将/装备/少量呆币 → 遇到瓶颈 → 挂机经验提升全队＋副本攒脑勋/将魂 → 配装、专武、升星、换阵 → 突破下一段地图。

| 成长项 | 当前规则 |
| --- | --- |
| 主线 | 持续向右行军；击杀每个小怪+10秘境进度，100召首领；击败后3秒自动下一关，失败重打；每场150秒上限 |
| 经验 | 首通1关开启；每分钟=12+最高已通关×0.35；最多缓存4h，领取日每日总计最多240分钟；上海零点刷新额度 |
| 防止追溯增益 | 换到更高已通关地图前，先按旧地图结算已挂机的时间并计入当天额度；不会把此前时间按新地图重算 |
| 升级 | 消耗 floor(100+30×等级^1.5) 经验及80+等级×40脑铢；等级上限300；不发固定“通关经验”，反复过关不能绕过经验额度 |
| 属性 | 基础等级倍率1.055^(等级−1)；装备加基础属性后再乘等级/星级倍率。数值曲线见ECONOMY_0.10.md |
| 阵容优势 | 好武将、星级、装备和专武允许同等级越过更多关；三将仍最多1神将2名将，不强迫只等等级 |
| 其他挂机 | 呆币沿用最多24h/1000缓存，独立于4h经验规则；不足整数保留余数，长离线不累积多天 |

缓存按领取日额度计算；本地时钟不防篡改。暂停/进入大厅不暂停现实时间收益。主线换图时的经验是已经过的挂机时间，不是击杀奖励。

**模拟边界示例（固定种子42、独立满血开打）：** Lv.1初始普通1星约到6关、神将1星约到45关、神将3星+专武约到85关；Lv.20分别约60/112/151关。这是引擎冒烟结果，不能证明真实留存或所有阵容的最优解。完整结果及可重复命令见[数值报告](docs/BALANCE_0.10.md)。

## 3. 装备与武将

### 3.1 装备

- 武器、战甲、兵符各1格，常规40件背包（独立测试档160件，可容纳132件全员配装）；同一装备只能被1名武将使用。转交会从原武将身上移走，不复制。
- 普通/精良/史诗装备均有图形，随首领胜利掉落；满包新掉落转换脑铢。分解只接受未穿戴的普通战利品，专武不可分解。
- 点击空格筛选对应部位；点装备再点穿戴，或拖入对应格；错部位不穿戴；已穿装备可点击卸下或拖回背包区域。
- 每人专武700脑勋、每把唯一，须已拥有对应武将；背包满或脑勋不足不扣费，兑换后可穿戴。
- 专武：猛攻/破阵技能伤害+25%；速攻普攻间隔−15%；护阵护盾量+50%（普通护阵带专武也可自盾）；治疗量+25%。不同武将的造型/武器名不同，目前是4类效果家族，尚非44套独立机制。
- 穿戴、升星、等级、阵型只影响新入场战斗；未完副本保留入场快照。

### 3.2 武将与升星

| 品级 | 数量 | 攻击型主动技能上限 | 治疗 |
| --- | --- | --- | --- |
| 普通 | 5 | 1目标 | 不配置治疗职业 |
| 骁将 | 8 | 2目标 | 最低生命比例存活队友1名，22%最大生命 |
| 名将 | 20 | 3目标 | 全体存活队友，12%最大生命 |
| 神将 | 11 | 全体敌人 | 全体并附状态；华佗20%群疗+12%生命盾，司马懿16%群疗+20%攻击，状态6秒 |

普攻单目标，小兵无主动技能，Boss允许范围攻击；治疗不复活、不伤害敌方。低品级专武/6星不会突破攻击目标上限。护盾和攻击状态刷新时间，不无限叠加；暂停冻结战斗状态时间。

所有44将从1星升到6星，逐次消耗20/40/60/100/160碎片。先用本将专属碎片，不足用通用将魂。每增加1星，相对1星基础攻防生命+16%（6星共1.8倍）；3星起蓄能+10%，6星攻击技能伤害+20%。升星不改变品级与三将上阵限制。

招募仍为100/1000呆币，60%/30%/9%/1%，十连至少骁将、80抽神将保底；重复给20本将碎片及200/500/2000/6000脑铢。完整名单与剧情送将见[ROSTER_0.10.md](docs/ROSTER_0.10.md)。神将不由主线直接送，旧档原有武将保留。

### 3.4 元素与持续状态

- 火焰：周瑜/陆逊/祝融/孙尚香的攻击技能，给原目标4秒灼烧，按施法者攻击12%/秒，每0.5秒结算。
- 冰雪：小乔全场攻击附25%攻速减缓4秒；实际延缓普攻冷却，不只是视觉变蓝。
- 毒雾：贾诩全场攻击附4秒中毒，攻击8%/秒；中毒期间受到治疗−25%。
- 雷霆：诸葛亮/赵云/孙策；风暴：关羽/吕布/庞统。当前只改变表现，不额外附加眩晕/击退。
- 治疗光环3.6秒，包括满血受疗；盾/战意采用既有6秒效果。所有状态暂停冻结；灼烧/中毒刷新取较高强度，不无限叠加，到期清空强度；盾可吸收持续伤害，已施加状态在施法者阵亡后仍可持续（本场尚未结束时）。

神将攻击覆盖全场，4秒天气层与1.5秒技能名横幅独立；同元素重放刷新，不会因下一名武将释放技能立即消失。骁将/名将的火焰等只对原2/3个目标施加。低品级全屏装饰不会伪装成全屏攻击。毒雾/治疗和冰雪的长线强度仍需阵容试玩校准。

## 4. 副本与奖励

| 副本 | 难度与频次 | 呆币/脑勋 |
| --- | --- | --- |
| 城门别闹 | 3次/日；本地自身守军镜像演练，2城上＋门前6选3，城墙破坏与落地；实际PvP待联机 | 胜180/12，败90/8 |
| 全服讨董 | 无限次、每次30秒，只取今日最高；按当日首次入场锁定地图档，避免当天换图改变比较口径 | 档位累计160–320呆币、20–30脑勋，仅补最高档差额 |
| 三将闹五关 | 3v5、99关，铁甲/人海/回春/断粮/火烧循环；新难度曲线为主线倍率(三将关数×3) | 每关首通100/10；失败无呆币/脑勋，不递增 |
| 草船借宝 | 2次/日，3次筹谋后3波；敌强度随最高地图每50关一个档，不按玩家每次升级自动追涨 | 胜260/12，败130/8 |

脑勋来自副本，**所有来源合计最多100/日**；城门/讨董/借宝各完成一次额外10脑勋（计入100上限，自动结算）。上限以外不缓存。日常另给通用将魂，每天最多20：城门胜2/败1，借宝胜3/败1，讨董当天首次6，三将胜2/败1。

完整满额日：3攻城胜36＋Boss最高档30＋2借宝胜24＋三类日常10=100脑勋；全败完成日常仍得70。由此名将14个满额日、神将21个、专武7个；**真实天数取决于能打到的档位、出勤和脑勋分配**，不是固定登录即送。

每天零点刷新（Asia/Shanghai）。有限次副本入场扣次，放弃不退不发奖；仅一个未完挑战，等级/装备/星级/专武/兵种/站位/筹谋快照不被途中养成修改，重载继续不重复扣次。每日型跨日失效，三将可跨日。真实攻城、全服排行与排名奖励均未实现，界面保留演练/个人成绩标记。
