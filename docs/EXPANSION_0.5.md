# 群将集结 · 0.5规则与数值初稿

日期：2026-10-30（Asia/Shanghai）。这是可试玩的本地规则，数值可继续调优；联机功能状态见SPEC.md。

## 武将与获取

四档：**小将 → 骁将 → 名将 → 神将**。共24位，基础职业包括群攻、破阵、速攻、护阵、治疗；颜色和人物仍为原创占位画面。

| 档位 | 武将 | 获取 |
| --- | --- | --- |
| 小将 | 廖化、周仓、管亥、简雍、糜竺 | 初始伙伴、招募 |
| 骁将 | 刘备、黄盖、孙尚香、徐晃、甘宁、许褚 | 主线剧情首通、招募 |
| 名将 | 关羽、张飞、赵云、诸葛亮、黄忠、张辽、陆逊、貂蝉、马超 | 主线指定关卡、招募、800军功任选 |
| 神将 | 吕布、曹操、周瑜、司马懿 | 招募、3000军功任选 |

剧情送将：第1关刘备、第3关黄盖、第5关张飞、第8关孙尚香、第10关徐晃、第12关赵云、第15关甘宁、第18关许褚、第20关关羽、第25关黄忠、第30关诸葛亮、第40关张辽、第50关陆逊、第60关貂蝉、第70关马超。每位只获得一次，已拥有的不重复给；神将不由主线直接赠送。

新存档从5名小将起步。0.4存档保留原五将、等级、铜钱和装备，并补齐已达到的剧情武将；不追发旧关卡呆币。武将库中可以查看来源，未获得的将不可上阵或穿装备。

0.6补充：主线与守城阵容最多5名武将；三将可选1–3名武将，武将加小兵共3人、最多1神将和2名名将。空位由刀盾、长枪、弓箭小兵补齐，详见BATTLE_STYLE_0.6.md。阵容保存后下一次战斗生效。怒气技能由阵容顺序中首位存活的武将释放，因此顺序也是搭配的一部分。治疗武将在场时，怒气技能附带群体治疗；护阵主将自疗，破阵主将集中攻击，其他职业群攻。尚未做24个独立专属技能。

## 呆币招募

- 单抽100呆币；十连1000呆币，无付费入口。
- 基础概率：小将60%、骁将30%、名将9%、神将1%；同档武将等概率。
- 十连至少1名骁将或以上；若前9抽全是小将且第10抽仍是小将，第10抽升为骁将。
- 连续79抽未得神将，第80抽必得神将；自然抽到神将即重置计数，单抽/十连共享且存档。
- 保底会影响最终分布，因此界面明确展示“基础概率”。神将保底可能是重复将，不保证未拥有。
- 重复武将转铜钱：小将200、骁将500、名将2000、神将6000。不会转军功，军功只从副本产生。
- 军功兑换直接选具体名将或神将，无随机、无轮换、无兑换次数限制；已有将不再扣积分。

## 主线与挂机收入

- 主线每关首通10呆币，每5关额外50；重复刷关仍有原有铜钱和装备，但不再给呆币。
- 第1关首通后开启挂机；按时间积累，24小时最多1000呆币，恰好一发十连。
- 离线最多存24小时；超过部分丢弃。未满1呆币的时间余数保留，多次领取不会多出收益。
- 本机时间倒退不重复发钱；正式版应使用服务端时间和账本。
- 不加入签到、广告、邮件或充值呆币来源。本轮来源只有主线首通、主线挂机和副本。

## 四个副本

| 名称 | 核心玩法 | 次数/收益 |
| --- | --- | --- |
| **城门别闹** | 异步玩家攻守、保存守城阵容；进攻选择对手，防守自动结算 | 每天3次进攻；胜120呆币+60军功，败30+15 |
| **全服讨董** | 30秒世界Boss冲分；每天无限打，只取个人最高参与全服排名 | 当日按最高伤害档补奖励差额，最多300呆币+120军功 |
| **三将闹五关** | 3v5、每5关一个特点循环并递增难度；阵容最多1神将2名将 | 1–99关，首通每关80呆币+40军功，失败无奖 |
| **草船借宝** | 三次航线筹谋后对战三波截江水匪，最后一波头目 | 每天2次；胜200呆币+100军功，败50+25 |

“每天3次”本轮按3次主动进攻设计；防守不要求在线，不额外消耗进攻次数。真实玩家匹配、对方守军快照、防守战报和全服排行榜尚未实现。**本地“城门别闹”按钮明确标注“攻城演练”，对手为自己的守军阵容快照；“全服讨董”只记录个人当日最高，不生成虚构玩家或排名。**

### 全服讨董

固定30个有效战斗秒，禁用倍速；计分目标不会被提前击杀。队伍全灭也等到30秒结束，不再产生伤害。只计我方造成的有效伤害。

| 当日最高伤害 | 当日累计呆币 | 当日累计军功 |
| --- | --- | --- |
| 参加一次 | 60 | 40 |
| 3000 | 120 | 60 |
| 10000 | 180 | 80 |
| 25000 | 240 | 100 |
| 50000 | 300 | 120 |

例如先打9000伤害领120/60，再打12000只补60/20；重复或更低成绩不再发奖。排行榜奖励留到真实联机后设计，当前没有排名奖励。

### 三将闹五关

每5关一组：铁甲关（高防御，破阵怒气技能）、人海关（五敌齐攻，群攻/速攻）、回春关（敌方每秒回复2.5%生命，需爆发）、断粮关（怒气恢复减半，依赖普攻和生存）、火烧关（我方每秒损失1.2%最大生命，需治疗与速战）。随关卡递增敌方数值。

这是职业与关卡特性的初版；未做所有99关的阵容解法和数值验收，不声称每一关都已平衡到必须换队。

### 草船借宝

出航前做3次筹谋，可重复选择，按同类次数线性累计：借东风每次攻击+20%；稳住船每次防御+35%；修船板每次生命+20%。三波敌人使用同一次筹谋加成。当前是筹谋+护送原型，尚无独立船体血量、随机地图或事件动画。

### 次数、跨日与结算

每天按Asia/Shanghai零点刷新。有限次副本在入场时扣次数，放弃不退、不发奖；仅允许一个未结束副本，保存入场阵容、等级、装备和筹谋。重载可继续该挑战，从该场开始重打，不重复扣次数；仅结算一次。主动重打已结束副本会消耗新次数。

每日型副本（攻城、Boss、借宝）的未完成挑战跨日失效，不能在新一天重复领取旧日奖励；三将闯关可以跨日继续。正式版还需要服务器保证防篡改、并发幂等和异常恢复。

## 经济上限示例

挂机24小时1000呆币；攻城3胜360；Boss最高档300；借宝2胜400。可重复的每日副本最多额外1060呆币和500军功，约6天可任选一位神将。三将首通与主线首通是额外的一次性收益，未计入此例。此处为初始数值方案，仍需留存和成长节奏测试。

## 联机阶段的实现边界

正式玩家攻守与全服排名需要微信身份、服务器、持久化账本和服务端战斗复算。建议将现有纯TypeScript战斗与配置共享给服务端，客户端提交操作/战斗票据，不直接采信客户端传来的伤害、胜负、余额和次数。

最小接口：身份会话；武将/阵容读取；守军快照保存；攻城匹配与入场票据；服务端战斗结算；Boss30秒挑战与日榜；呆币/军功招募兑换账本。所有消费和发奖要同事务提交并使用唯一结算ID。当前未配置或付费开通云服务，也未发送玩家数据。
