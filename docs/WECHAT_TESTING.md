## 全面屏真机回归

- [ ] 在同一台全面屏手机确认顶部胶囊和钱包不重合，切后台回来保持正确布局。
- [ ] 另一台窄屏或胶囊左侧空间较少的设备上，确认钱包回到胶囊下方。
- [ ] 战况和版本在浅色地图上可读，菜单展开后状态条不遮按钮，底部按钮避开手势区。
- [ ] 技能横幅在自动施法时避开左右快捷按钮，全场特效铺到战斗区域边缘。
- [ ] 首次测试默认音乐关，普攻、技能、Boss 双嗡能播放。打开音乐、关闭再重载，验证用户选择保留。
- [ ] 受伤聚气与满能自动，世界 Boss 终结、破城碎石、装备拖动和存档。

构建、预检与版本边界见 [构建记录](BUILD_REPORT.md)。
