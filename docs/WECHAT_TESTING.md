## 现在让朋友试玩

1. 管理员登录微信公众平台，进入“成员管理 → 体验成员 → 添加成员”。输入朋友的**微信号**，核对搜索出的账号并按提示确认；不是填昵称。当前待添加：`a designated tester`。
2. 进入“版本管理 → 开发版本”，找到**0.11.1**，通过右侧菜单选为体验版。
3. 从后台取得**体验版二维码**，交给已添加的账号扫码。不要把此前仅用于开发预览的临时二维码当体验版码。
4. 若仍提示无权限：确认扫码微信与添加的微信号一致、添加已保存、当前版本确实有体验版标记；退出扫码页面后重新扫最新体验码。

仅试玩优先体验成员；开发者还可以参与代码开发/上传等，不应为了试玩无必要扩大权限。[引擎官方微信部署流程](https://docs.unity.cn/cn/tuanjiemanual/1.7/Manual/UploadWeixinMiniGame.html)说明自己的AppID、预览测试成员、上传后到后台设体验版的步骤。本文只使用通用微信流程，不采用Unity专属配置。
