# 《呆脑三国》首次伙伴内测

## 转发给体验伙伴

**《呆脑三国》第一次小范围内测来啦。** 这是一款夸张漫画风格的单机三国刷宝小游戏。你带主公和随将过章节、攒破阵进度见首领，刷出新装备和将帖，再换阵容挑战高难度。首次进入会看到三页「出征手册」，之后也可以在营地回看。

### 先玩一圈

1. **从破旗坡出发。** 在营地点「出营 · 章节战图」，看完开篇进入第一张图。战斗自动推进，清怪积攒破阵进度，进度满了就出首领。精英怪给的进度更多。首通破旗坡可结识程普并获得破旗短刀。
2. **换装再打。** 在「行装 · 整装」给主公和随将穿武器、战甲、兵符。点装备可看属性，穿戴支持点按和拖动。打磨增加基础属性，刻阵提供开场护盾或增攻，巧作及以上装备可压阵。粉橙装按角色的装备类型穿戴。
3. **试试不同阵容。** 主公必须出战，可带 0–4 名随将或小兵。拖动调整站位，怒气满后点头像放技能，也可以开启自动施法。主公升级会带动随将升级。重复将帖变为专属碎片，升星时可以用脑力补足。
4. **刷装备或继续推图。** 主线共 50 章、400 张图，每张图有探路、硬仗、翻天三档。备战弹窗可切难度、点掉落看属性。体力每天早上 7 点恢复到 300，单场消耗随波数变化。连刷遇败即停，五倍结算只打一场，失败也扣五倍体力。
5. **离开前可以派队。** 选打过的战图开启离线挂机，最多积攒 4 小时，回来结算时扣体力。行军药铺的鼓劲汤能加快聚气，疾行汤可开 4 倍速。

### 奇战营的四个玩法

| 副本 | 怎么玩和能拿什么 |
| --- | --- |
| 赤门惊坛 | 章末翻天首通后开放对应章节。消耗赤门令，闯门、击坛、迎战巨将，有概率掉稀有将帖、专武、高阶粉装和橙装。 |
| 军器换班 | 每两天轮换一项任务，刷炉砂、阵纹墨或压阵印，用于整装。 |
| 魔王轮番揍 | 每周更换魔王，30 秒内尽量打出高伤害。三位魔王各有八档伤害奖励及不同奖品。 |
| 城门别闹 | 横向推进、破门再打守军。获胜可额外获得赤门令，并有小概率掉落续火券，用于跨品级转移同部位装备的打磨能量。 |

**这次内测**的战斗和挂机经验都是双倍，武将、装备、材料和赤门令靠游戏内取得。进度保存在当前设备，声音可在营地设置。欢迎告诉我卡在哪章、装备是否好找、自动战斗节奏是否舒服；遇到问题请带上设备型号、页脚版本和截图。
