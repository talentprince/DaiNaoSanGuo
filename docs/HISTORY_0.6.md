## 本轮战斗样式

- [x] 主线改为横向向右行军，背景向左循环；战场内容有边界裁剪。
- [x] 秘境进度与技能怒气独立。每杀小怪+10秘境进度，100时首领现身；只有首领击败才通关。
- [x] 主线击败首领结算后3秒自动进下一关；失败需重打本关、秘境进度重置。Demo暂上限99关。
- [x] 武将拆分头、躯干、双臂、双腿与武器；走路摆腿摆臂、呼吸、挥砍/拉弓/持枪、受击和倒地。
- [x] 普攻飞箭、法弹、刀光、枪刺；技能有群体斩击、贯穿光束、箭雨、盾形光效、治疗光环与浮字。
- [x] 世界Boss上方巨大模型，下方我方横排面对Boss；固定30秒计分，目标不被提前击杀。
- [x] 城墙为可攻击实体；最多2名已选守将站城上，城墙存活时承伤减少60%。破城后减伤解除、守将落地，并显示碎石效果。
- [x] 可保存守城阵容和城上两将；本地攻城演练使用该守军快照。真实玩家守城仍待联机。
- [x] 三将3v5横向布局，双方进场向中间移动；接敌前不攻击。

以上代码与规则已实现。具体画面验收与发布构建结果见下方验证矩阵；未通过实际运行的项不据此宣称已验收。

## 工程模块

- BattleEngine：纯TypeScript战斗、秘境、计分和城墙规则。
- HeroCatalog / BattleConfig / ActivityConfig：武将、兵种、主线和副本配置。
- ProgressStore：本地资源、招募兑换、存档迁移、日次数和挑战快照。
- UnitActor / BattleStage / CombatEffects：分部件角色、场景与动画效果。
- BattlePreview：Cocos场景协调；MetaPanel / InventoryPanel：大厅与背包。
- scripts/build.mjs：Web/微信可复现构建，Creator成功码36归一为0。

## 已知限制与下一阶段

- 当前为本地原型，真实玩家攻守、全服排名、微信身份和服务端账本尚未接入。界面明确标注演练/待联机，没有虚构玩家排名。
- 本机资源、时钟和随机数不防篡改；正式线上奖励与战斗必须服务端校验。本轮未开通或付费部署云服务。
- 程序化2D关节角色，尚非骨骼资源/3D模型；无24套独立专属技能、正式美术或音效。
- 建议同一origin只开一个游戏页，尚无多标签并发写存档同步。
- 主线与三将关卡范围1–99，未逐关完成平衡；当前只有武器部位和固定装备属性。
- 下一阶段：体验调优、独立技能与职业配合、真实联机攻守/榜单、正式资源和真机验证。
